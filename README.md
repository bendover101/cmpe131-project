# Travel Agency API

Run the API from the project root with either of these commands: BACKEND

```bash
uv run uvicorn app.main:app --reload
```

or:

```bash
uv run uvicorn main:app --reload
```

`main.app:app` is not a valid import path in this repository.


# Change RAPIDAPIKEY located in the .env files to your own RAPID API KEY booking.com

  Example: RAPIDAPI_KEY = YOUR_OWN_KEY1234


# Front END

  npm run dev

  MUST RUN FRONT AND BACK END to get full results
